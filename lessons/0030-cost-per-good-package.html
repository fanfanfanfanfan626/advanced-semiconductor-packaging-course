Semiconductor & Advanced Packaging · Lesson 0030

每颗合格封装的成本模型

先进封装的正确比较对象不是“封装步骤多少钱”，而是交付一颗满足规格的合格系统需要消耗多少 die、材料、设备时间、测试与良率损失。

本课结果

能建立 cost per good package 模型，并解释 chiplet 何时省钱、何时把成本转移到封装与测试。

Core model

总投入如何摊到合格产品

单位合格成本 = 总 die + 互连/基板 + 组装 + 测试 + 良率损失 + 折旧/间接成本

Die 成本

考虑各节点晶圆成本、die 面积、单 die 良率、KGD 测试与备用数量。 [1]

Package BOM

加入 interposer/bridge、substrate、HBM、凸点、underfill、mold、TIM 和 lid。

Process + test

按设备时间、重复层数、组装、量测、burn-in 和系统测试计入。 [3]

Compound yield

把各关键步骤良率和返工边界组合，除以最终合格数量。 [2]

Three anchors

三个必须抓住的判断点

GOOD

分母必须是合格产品

名义投入低但最终良率差，单位合格成本可能更高。

NODE

Chiplet 可优化节点分配

数字逻辑迁移先进节点，模拟、I/O 或缓存留在成熟节点，可能改善面积与成本。

NRE

量产成本之外还有 NRE

Mask、IP、封装设计、验证和软件投入会随销量分摊，影响小批量产品经济性。

Mission lenses

工程、投资与科研同时看

工程镜头

对面积、良率、chiplet 数、attach yield、基板规格和测试时间做敏感性分析。

投资镜头

区分产品 ASP 上升与供应商利润上升；爬坡、折旧和低利用率可能暂时压低毛利。

科研 / 专业镜头

可建立参数化 cost/yield model，并用公开数据做区间和蒙特卡洛分析。

Worked decision

避免只比较 die 良率

情境：Chiplet 方案的各小 die 良率更高，但需要昂贵 interposer、更多测试和多个高难度 attach。

看判断标准

必须比较最终每颗合格封装成本

单 die 良率优势可能被封装 BOM、assembly yield、测试和 NRE 部分抵消。

Primary sources

本课一手资料

  1. AMD, Chiplet Architecture White Paper：Chiplet 的良率、复用与节点优化优势，以及封装、互连、热和成本约束。
  2. IEEE HIR 2023, Test Technology：多 die、KGD、堆叠、设计可测性与系统级测试。
  3. Intel Tech 101, How Silicon Die Become Chip Packages：Chip attach、epoxy、lid、burn-in、最终测试与平台验证的官方流程。

本课压缩结论

先进封装经济性必须以每颗合格系统为分母；chiplet 改善某些成本，也会新增互连、组装、测试和验证成本。
