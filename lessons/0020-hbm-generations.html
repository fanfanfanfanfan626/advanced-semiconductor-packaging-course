Semiconductor & Advanced Packaging · Lesson 0020

HBM 代际升级到底升级什么

HBM 的代际升级不只是单一速度数字。总线宽度、每 pin 速率、堆叠层数、容量、base die、功耗、热、封装接口和客户验证共同决定系统价值。

本课结果

能把 HBM 规格分成带宽、容量、能效、制造与系统集成五类，而不只比较代际名称。

Core model

从单个 pin 到整套 AI 系统

单堆栈带宽 ≈ I/O 宽度 × 单 pin 数据率

接口宽度

更宽的总线直接增加并行数据路径；HBM4 进一步扩大接口宽度。 [1]

单 pin 速率

更快信号提高带宽，也增加信号完整性、功耗和封装验证难度。

容量与层数

更多 DRAM die 和更高单 die 容量提高每 stack 容量，但加重薄化、堆叠、热与良率约束。 [2]

Base die + package

Base die、PHY、CoWoS/其他平台、GPU 控制器和系统软件共同决定实际表现。

Three anchors

三个必须抓住的判断点

SPEC

带宽不等于容量

带宽表示每秒传多少，容量表示能存多少；AI 工作负载可能同时受二者限制。

YIELD

规格必须穿过量产良率

层数、接口和 base die 越复杂，越要核对成熟良率、客户认证与稳定供货。

SNAP

代际信息要标日期

本课规格状态以 2026-08 为快照；投资研究必须重新核对厂商和标准披露。 [1]

Mission lenses

工程、投资与科研同时看

工程镜头

用带宽、容量、pJ/bit、温度、堆叠高度、接口宽度和 base die 工艺共同比较。

投资镜头

关注 qualified supply、良率、客户组合、长期协议、产能机会成本和封装配套，而不只看名义需求。

科研 / 专业镜头

可研究 DRAM—base die 协同、热、测试、信号、功耗和系统数据流。

Worked decision

拆解“带宽翻倍”

情境：新一代 HBM 宣称单 stack 带宽显著提高。

看判断标准

先拆成总线宽度与单 pin 速率，再检查系统边界

还需核对容量、功耗、温度、控制器、封装、良率和客户工作负载，才能判断实际价值。

本课压缩结论

HBM 代际升级是接口、速度、容量、base die、能效、热与封装的共同升级；任何单一数字都不完整。
