HBM 为什么既要堆高，也要靠近 GPU

“堆高”解决容量、面积与内部连接；“靠近”让 GPU 与内存之间拥有大量短通道。HBM 是存储器设计与先进封装共同完成的系统。

本课胜利条件

看到 GPU + HBM 结构时，能说清：HBM 内部为什么是 3D，整个 GPU-HBM 封装为什么通常称为 2.5D。

看单组 HBM：3D

多层 DRAM die 垂直堆叠，通过 TSV（穿硅通孔）与 microbump 建立上下连接。Micron 将 HBM 定义为 3D-stacked SDRAM architecture。[1]

看整个 GPU + HBM：2.5D

GPU 与若干 HBM stack 横向并排在中介层上，由中介层提供密集布线。TSMC 将 CoWoS 描述为整合 SoC 与 HBM 的 2.5D 平台。[2]

记忆句：HBM 自己是“一栋 3D 公寓”；GPU 与多栋 HBM 公寓并排建在同一个中介层园区，整个园区是 2.5D。

02 · Why stack

堆叠不是为了看起来先进

容

容量密度

多层 DRAM 向上堆叠，在较小封装占地内提供更多存储容量。

宽

超宽接口

大量 TSV 与 I/O 数据路径并行工作。Micron 的示例 HBM cube 使用 1024-bit 宽接口，而不是只依赖极高单 pin 速率。[1]

短

短距离

HBM 与 GPU 通过同一封装中的中介层连接，数据不必经过更长的板级路径，有利于每比特能耗。

03 · Reuse lesson 4

HBM 把“更宽、更短”同时实现

更多数据路径接口变宽
GPU-HBM 距离短中介层内连接
带宽 ↑N × R 增大
每比特能耗 ↓相对板级链路
喂饱计算单元减少等待数据

Micron 明确将 HBM 的高吞吐归因于高度并行的宽接口，并说明与 CPU/GPU 通过硅中介层近距离集成可缩短数据路径。[1]

04 · No free lunch

投资研究不能只数 HBM 层数

价值来源

  • 更高内存带宽和容量
  • 更低数据移动能耗
  • 支撑更多 GPU/加速器计算单元
  • 推动 HBM、TSV、中介层和先进封装需求

新增约束

  • 多层 DRAM 的堆叠、薄化、键合与测试
  • GPU、HBM 与大中介层的组装良率
  • 封装热、供电与翘曲控制
  • HBM 产能、先进封装产能与系统验证

投资镜头：“HBM 需求增长”会同时拉动存储制造与先进封装，但利润由谁获得，要看稀缺环节、良率、扩产速度、议价能力和客户替代方案，不能只看出货量。

06 · Read one primary source

课后只读 FAQ

1°

Micron：High-bandwidth memory

只读“What is HBM?”和“How does HBM differ from DDR5?”两问。找出三个关键词：3D stacked、ultra-wide interface、silicon interposer。

本课来源

  1. Micron, High-bandwidth memory：3D DRAM 堆叠、TSV、1024-bit 宽接口和硅中介层近距离集成。
  2. TSMC, CoWoS：SoC、逻辑 chiplet 与 HBM stacks 的 2.5D 中介层集成。
  3. SK hynix × TSMC：HBM 内部 3D 与整个逻辑—HBM 模块 2.5D 的术语说明。

本课压缩结论

GPU 与 HBM 并排属于 2.5D 系统，HBM 内部是 3D 堆叠；其高带宽核心是极宽接口与近距离互连。
