# Security

The published course is a static website. It has no backend, account system, analytics, remote code loader, or data-upload feature. Reading progress is stored only in the visitor's browser `localStorage`.

For a potentially sensitive security issue, use [GitHub private vulnerability reporting](https://github.com/fanfanfanfanfan626/advanced-semiconductor-packaging-course/security/advisories/new). For ordinary broken links, display problems, or content corrections, open a regular Issue. Do not include credentials, private learner records, or other sensitive information in a public report.
