先进封装技术路线图

把 2D、2.5D、3D、fan-out、混合键合、基板、CoWoS、InFO、EMIB、Foveros、UCIe 与 HBM 放到统一坐标系中。

判断规则

01

先描述物理结构，再使用 2D、2.5D、3D 或 fan-out 标签。

02

微凸点依靠凸点建立接触；混合键合把介质键合与铜—铜连接结合，间距潜力更小但表面要求更严。

03

封装基板完成尺度转换、供电、信号和机械承载；ABF 是积层基板常用层间绝缘材料，不是整块基板。

04

CoWoS-S、R、L 的核心差异是整片硅、RDL 与局部硅互连怎样组合，而不是简单代际高低。

05

EMIB 是局部硅桥思路；Foveros 是包含垂直堆叠和中介层方案的技术族。

06

UCIe 标准化 die-to-die 接口与管理测试，但不会自动解决制造、热、供电、封装兼容和商业生态。

本模块术语

2D / 2.5D / 3Ddie 在基板上连接、die 在高密度中介层/桥上并排连接、活性 die 直接垂直堆叠的三类空间结构。
Fan-out把 die 嵌入重构载体并用 RDL 将端口扩展到 die 外部的封装方法。
Hybrid bonding介质表面键合与铜—铜直接互连结合的细间距键合方式。
ABF / Glass coreABF 是积层绝缘材料；玻璃芯基板利用尺寸稳定性、平整度和可调 CTE 支持进一步缩放。
CoWoS / InFO / SoICTSMC 的 2.5D、fan-out 与前段 3D 堆叠技术族。
EMIB / FoverosIntel 的局部硅桥与 2.5D/3D 集成技术族。
UCIe覆盖封装内 die-to-die 物理层、协议、管理、测试和软件模型的开放标准族。
