Module 01 · Print-friendly

物理与封装底座

从 wafer、die 和 package 出发，建立良率、互连、HBM、散热、供电、可靠性、测试与装配的完整因果链。

判断规则

01

Chiplet 描述架构拆分，2.5D/3D 描述物理集成方式；两者不能互相替代。

02

面积增大通常增加遇到致命缺陷的机会；chiplet 改善单 die 良率，但新增互连、封装、测试与系统良率约束。

03

带宽的第一层直觉是通道数乘以单通道速率；近距离互连通常有利于每比特能耗。

04

HBM 内部是 3D 堆叠，GPU 与 HBM 并排放在中介层上时整体通常是 2.5D。

05

热量越集中、热路径越困难，温度越容易升高；供电在同功率低电压下需要更大电流。

06

先进封装必须把信号、供电、散热、机械可靠性、测试与制造良率一起设计。

本模块术语

Wafer / Die / Package晶圆是制造载体，die 是切割后的裸片，package 是把 die 与互连、供电、散热和保护结构组成可使用器件。
Chiplet用于多 die 系统集成的功能裸片模块，属于架构与功能划分概念。
Yield / KGD良率必须说明阶段；KGD 是组装前已经过测试并确认可用的裸片。
HBM多层 DRAM 垂直堆叠、采用超宽接口并与计算 die 近距离连接的高带宽存储器。
Interposer / TSV / Microbump分别建立平面高密度布线、穿硅垂直导通和两个器件界面的金属接触。
Power density / Thermal resistance分别描述单位面积功耗和热量沿指定路径传出的困难程度。
PDN / IR dropPDN 是完整供电网络；IR drop 是电流经过路径电阻造成的压降。
CTE / WarpageCTE 是热膨胀系数；不同材料膨胀不一致会产生应力和封装翘曲。
